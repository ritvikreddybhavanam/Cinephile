📋 Data Dictionary & Key Constraints

Unique Constraints & Business Rules:

  • users: Unique index on emailaddress.
  • reviews: Unique composite index on (movie_id, user_id) — one review per movie per user.
  • watchlist: Unique composite index on (user_id, movie_id) to prevent duplicate bookmarks.
  • liked_movies: Unique composite index on (user_id, tmdb_movie_id).
  • watched_movies: Unique composite index on (user_id, movie_id).

Service Communication & Data Flow:

  • TMDB Integration: Cached movie metadata fetched using TMDB API Bearer token.
  • ML Predictions: Client supplies movie characteristics (budget, runtime, release date, country, genres); FastAPI transforms inputs and computes predicted revenue in USD & Millions.
  • Security: Stateless JWT tokens with user claims and verification.
